Cách chạy website trên local

Website có PHP nên cần một chương trình PHP chạy nền. Trình duyệt sẽ mở địa chỉ http://127.0.0.1:8082/ để gửi yêu cầu cho chương trình đó. 127.0.0.1 nghĩa là chính máy đang dùng; 8082 là cổng nhận yêu cầu.

1 Chạy trên Windows bằng XAMPP hoặc PHP

  1. Cài PHP 8.1+ từ windows.php.net, hoặc XAMPP từ apachefriends.org. Nếu dùng XAMPP, script nhận đường dẫn mặc định C:\xampp\php\php.exe.
  2. Giải nén ZIP bằng Extract All. Mở 01-Source-code; bạn cần thấy CHAY-ARTIO.cmd, index.php, thư mục scripts và storage.
  3. Bấm đúp CHAY-ARTIO.cmd. Script tạo/nâng cấp schema, chuẩn bị admin/admin và khởi chạy server. Không cần bấm Start MySQL hay Apache trong XAMPP vì dùng PHP server riêng.
  4. Khi thấy ARTIO LOCAL và URL, mở http://127.0.0.1:8082/. Mở /admin.php rồi đăng nhập admin/admin.
  5. Giữ cửa sổ lệnh mở trong lúc xem website. Ctrl+C dừng server; nếu có câu hỏi kết thúc batch job, chọn Y. Dừng server không xóa dữ liệu.

Nếu PHP nằm ở đường dẫn khác

Mở Command Prompt tại thư mục 01-Source-code và gõ lệnh dưới đây, thay đường dẫn bằng vị trí php.exe của bạn:

set "PHP_BIN=C:\duong-dan\php.exe"
CHAY-ARTIO.cmd

Nếu thiếu PDO SQLite hoặc fileinfo

Kiểm tra PHP đang dùng và các extension:

"C:\xampp\php\php.exe" --ini
"C:\xampp\php\php.exe" -m

Mở php.ini được lệnh --ini chỉ ra. Nếu các dòng bên dưới đang bắt đầu bằng dấu chấm phẩy, bỏ dấu chấm phẩy rồi lưu. Dừng và mở lại CHAY-ARTIO.cmd.

extension=pdo_sqlite
extension=sqlite3
extension=fileinfo

2 Chạy trên macOS hoặc Linux

Cài PHP 8.1+ theo cách phù hợp với hệ điều hành. Trên macOS đã có Homebrew có thể dùng brew install php. Trên Ubuntu có thể dùng sudo apt install php-cli php-sqlite3. Sau đó kiểm tra php -v và php -m, bảo đảm có PDO, pdo_sqlite và fileinfo.

  1. Mở Terminal tại 01-Source-code. Cách dễ: gõ cd rồi kéo thư mục vào Terminal và Enter; hoặc dùng đường dẫn trong dấu ngoặc kép.
  2. Chạy sh scripts/setup-local.sh. Khi server đang chạy, mở http://127.0.0.1:8082/.
  3. Mở /admin.php và đăng nhập admin/admin. Giữ terminal mở; Ctrl+C để dừng.
cd "/duong/dan/ARTIO-BAN-GIAO-20261007/01-Source-code"
sh scripts/setup-local.sh

Nếu không gọi được php bằng tên ngắn, đặt PHP_BIN chỉ trong lệnh chạy này:

PHP_BIN="/duong/dan/php" sh scripts/setup-local.sh

3 Sau khi đã chạy lần đầu

setup-local.sh và CHAY-ARTIO.cmd tạo/cập nhật database và đặt lại tài khoản local admin/admin mỗi lần chạy. Không ghi đè khóa học/brush đã sửa nếu dữ liệu đã tồn tại. Khi muốn chỉ mở server, macOS/Linux dùng sh scripts/start-local.sh. Windows dùng các lệnh dưới trong Command Prompt sau lần setup đầu:

"C:\xampp\php\php.exe" -d upload_max_filesize=6M -d post_max_size=8M -d display_errors=0 -S 127.0.0.1:8082 router.php

Trang chỉ hiện code PHP hoặc không hiện gìMở bằng URL http://127.0.0.1:8082/, không mở file PHP trực tiếp; chạy đúng router.php trong 01-Source-code.

Font, video hoặc link ngoài không tảiFont Hero có sẵn local; font nội dung có thể dùng font thay thế. Google Fonts, Facebook, video và nguồn brush cần mạng.

5 Sao lưu và khôi phục

  1. Dừng server bằng Ctrl+C trước khi sao lưu để có bản SQLite nhất quán.
  2. Sao chép storage/artio.sqlite và toàn bộ uploads sang nơi khác. Nếu sửa code thì sao lưu thêm source.
  3. Muốn khôi phục, dừng server rồi chép database và uploads của bản sao lưu vào đúng vị trí. Mở server lại.
  4. Muốn demo sạch, giải nén ZIP gốc vào thư mục mới. Không xóa database đang chứa nội dung bạn muốn giữ.

storage/ADMIN-ACCESS.txt ghi tài khoản local. Database lưu password_hash, không lưu mật khẩu gốc. Tài khoản admin/admin được chuẩn bị cho bản local này.
