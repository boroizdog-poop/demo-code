Kết cấu code và ý nghĩa từng phần

Bạn có thể hình dung website là một cửa hàng trưng bày tài nguyên. Giao diện là phần người xem thấy; PHP là người lấy đúng nội dung ra; database là kho lưu nội dung. Admin là quầy quản lý dùng để cập nhật kho. Không có một database riêng cho admin và một database khác cho trang ngoài.

1 Các khái niệm cơ bản

Khái niệmHiểu đơn giản
HTMLKhung nội dung: tiêu đề, đoạn văn, ảnh, nút và form. Trong dự án này PHP tạo HTML rồi gửi về trình duyệt.
CSSQuy định màu, font, khoảng cách, kích thước ảnh và cách xếp phần trên desktop/mobile.
JavaScriptPhản hồi sau khi trang hiện: mở dialog, gửi đăng nhập, bấm lưu, chuyển slide, upload và báo lỗi.
PHPChạy trên server local để kiểm dữ liệu/quyền, đọc database và tạo trang. Trình duyệt không tự thực thi PHP.
APIapi.php là điểm nhận yêu cầu thao tác. action cho biết muốn đăng nhập, lưu khóa học hay sửa CMS.
SQLite và SQLSQLite là hệ quản trị dữ liệu dùng một file. SQL là câu lệnh đọc/ghi các bảng trong file đó.
PDOCông cụ của PHP để kết nối database; tránh để mỗi trang tự viết một cách kết nối khác.
Session và CSRFSession giữ trạng thái tài khoản qua cookie; CSRF là token kiểm request thay đổi dữ liệu có thuộc phiên hiện tại không.
MigrationScript nâng cấp cấu trúc dữ liệu, thêm cột/bảng/quan hệ cần thiết, có kiểm tra trước để không thêm trùng.

3 Từng file làm gì

File hoặc nhóm fileÝ nghĩa
index.phpTrang chủ; đọc khóa học, brush và CMS; sinh Hero, About, poster, người mới, New Share.
courses.phpThư viện khóa học; nhận category/sort từ URL, lọc và tạo thẻ.
search.phpTrang tìm kiếm cả khóa học và brush bằng tham số q.
course.phpChi tiết khóa học, chương/bài, nút lưu, bình luận; kiểm đăng nhập và trạng thái.
brush.php / brush-detail.phpDanh sách và chi tiết brush, thông tin nguồn và bình luận.
account.phpĐọc các khóa học người dùng đã lưu qua saved_courses.
admin.phpChọn màn hình quản trị theo view/section hoặc editor theo new/edit; kiểm role admin.
api.phpNhận action, kiểm CSRF/quyền/dữ liệu, ghi database hoặc upload; trả JSON.
router.phpCho phép các route công khai và file assets/uploads; chặn file database, script và cấu hình qua URL.
bootstrap.phpHàm session, user, CSRF, truy vấn khóa học, chuẩn hóa tìm kiếm, validation và escape HTML.
config.php / config.local.phpTạo PDO. Bản local chọn SQLite; biến ARTIO_* có ưu tiên hơn config.local.php.
includes/layout.phpHeader, footer, card khóa học, dialog đăng nhập và yêu cầu login.
includes/site-content.phpDanh sách trường CMS, chữ/ảnh mặc định, đọc giá trị site_settings.
includes/admin-ui.phpBản đồ 7 khu vực và form sửa CMS của admin.
includes/brushes.php / comments.php / artwork.phpTruy vấn/seed brush; phần bình luận; xử lý nguồn và credit ảnh.
assets/style.css / gallery.css / site-refinements.cssKiểu chung, thư viện/chi tiết và các bổ sung giao diện.
assets/landing.css / landing.jsBố cục và motion trang chủ; chỉ nạp landing ở trang chủ.
assets/admin.css / admin.jsGiao diện admin; gửi form, upload, editor nhiều bước.
assets/app.js / gallery.jsAuth/lưu/bình luận/dialog; reveal và bộ điều khiển New Share duy nhất.
assets/landing/* / assets/images/*Logo, font Hero và ảnh mẫu. Đây là file thật dùng khi hiển thị.
scripts/setup.php và migrate-*.phpTạo bảng, dữ liệu mẫu; nâng cấp bảng/cột/quan hệ/mặc định một cách lặp lại được.
scripts/create-admin.phpTạo hoặc cập nhật tài khoản quản trị bằng lệnh terminal.
storage/artio.sqlite / uploads/*Database lưu lâu dài; ảnh upload lưu thành file. Chỉ database lưu đường dẫn ảnh.
tests/integration.pyBộ kiểm thử HTTP trên SQLite tạm, không phải thành phần phục vụ trang web.
database.sqlSchema MySQL tham khảo; không cần import khi chạy local SQLite.

4 Muốn sửa một phần thì đi đâu

Muốn thay đổiChỗ sửa phù hợp
Đổi chữ/ảnh trang chủĐăng nhập admin → đúng mục Hero/About/Không gian tranh/... rồi lưu. Không cần sửa HTML/PHP.
Đổi một khóa học hoặc chương/bàiAdmin → Khóa học & hướng dẫn → Chỉnh sửa. Sửa nội dung, ảnh, bài và trạng thái.
Đổi brush hoặc link tác giảAdmin → Brush library. Ghi đúng source HTTPS và thông tin sử dụng.
Đổi link FacebookAdmin → Menu & liên hệ Facebook. contact.php cũng chuyển tới link đó.
Đổi bố cục, kích thước hoặc màu trang chủassets/landing.css; nếu thay motion, xem landing.js và gallery.js.
Đổi bố cục thư viện, hiệu ứng zoom chungassets/gallery.css, với một số kiểu nền chung ở style.css.
Thay logic lưu dữ liệu hoặc quyềnapi.php và bootstrap.php. Sửa giao diện không đủ để thay quyền; API phải kiểm tra.
Đổi database localconfig.local.php hoặc biến ARTIO_DB_DRIVER/ARTIO_DB_PATH. Không sửa file SQLite bằng editor văn bản.

5 Một số điểm dễ hiểu nhầm

  • Đổi CSS chỉ đổi cách nhìn, không tự tạo tài nguyên mới trong database.
  • index.php là trang hoạt động. Bản HTML tĩnh từ demo là tham khảo; không cần thêm index.html vào gói để chạy.
  • storage/artio.sqlite là dữ liệu, không phải code. Xóa nó sẽ mất những nội dung lưu trong bản đó.
  • uploads chứa ảnh người dùng tải lên. Đổi đường dẫn trong database không di chuyển ảnh thật.
  • Python và Node.js không bắt buộc cho website. Không có bước npm install hoặc build frontend.
  • Menu Liên hệ mở Facebook. Hộp thư và newsletter còn phần code/API tương thích; giao diện công khai hiện tại không có form cho hai phần đó.
